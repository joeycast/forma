# 0.5.1 line editing verification

Verified 2026-09-22.

41 automated tests, the production build, and `npm publish --dry-run` pass. Install docs, the agent setup prompt, and hosted update instructions use the v0.5.1 GitHub release tarball. `forma-diagrams` is still not on the npm registry.

0.5.1 lets a selected line be dragged onto any connection point and lets a straight stretch slide while its ends stay attached. Outline selection no longer blanks the canvas. The element inspector lists that shape's lines and hides document-wide theme and layout controls.
