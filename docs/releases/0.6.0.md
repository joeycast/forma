# Forma 0.6.0

Status: prepared for release; npm publication is pending.

This minor release expands the graphical editor and makes diagram editing and saving more predictable. The native document remains version 2; the embedded design-system format remains version 1.

- Edit everyday node, edge, group, layout and design-system properties with effective values, style sources and scoped resets. Cosmetic edits preserve classic components and unrelated geometry.
- Insert 12 native shapes, plus circle and square choices. Rendering, text regions, connection boundaries and aspect constraints share the shape registry.
- Move and manipulate connectors without accumulating generated corners as fixed intent. Cancelled gestures and clicks without movement leave the document unchanged.
- Copy, paste, duplicate, group and ungroup selections; release position pins and reset routes explicitly.
- Recover document-scoped drafts, including unnamed prior-session drafts. Rename, duplicate, trash and restore library entries with conflict checks.
- Save immutable design-system revisions separately from applying portable snapshots. Author roles, defaults and previews through graphical controls.
- Use transactional IndexedDB for browser library and design-system snapshots. Legacy localStorage records migrate once without changing their original bytes. Hosted/file adapters enforce authoritative revisions, quotas and token revocation.
- Run layout and inspection in a cancellable worker while preserving the last successful scene. Block stale visual exports and retain routing diagnostics.
- Preview and apply revision-bound agent patches through REST, CLI and MCP, with structured errors and change summaries.

## Try the local package

Requires Node.js 22 or newer; qualification used Node 24 on Linux. Download the test tarball and run this from the folder containing it:

```sh
npx --yes --package ./forma-diagrams-0.6.0.tgz forma serve --directory ./forma-test-diagrams
```

Open `http://127.0.0.1:4242`. Saved diagrams go into `forma-test-diagrams`; stop the server with Ctrl+C. The first run downloads package dependencies. No global installation or source build is required.
