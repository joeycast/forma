# Forma mindmap

Use [the shared file and CLI workflow](../forma/SKILL.md). This skill supplies composition guidance, not a required diagram type.

Start with one central question or concept and a small number of distinct branches. Label branches with concepts, not vague category names. Use descriptions for supporting ideas and avoid coloring every node differently.

A one-sided map can use automatic RIGHT layout; a balanced map can use grid cells around the center and straight, arrowless edges. Use an ellipse for the central concept and rectangles for branches. Nested groups are useful only for actual conceptual boundaries.

[The mind map example](../../examples/gallery/mindmap.forma.json) uses a cross composition around one question. Let the design system set the visual identity. Check that the center remains dominant and connectors do not pass through unrelated concepts. This grid approach also works for explanations without a named diagram category.
